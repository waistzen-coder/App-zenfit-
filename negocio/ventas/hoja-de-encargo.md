# Hoja de encargo

Para mandar por WhatsApp o correo cuando el cliente dice que sí. Con que conteste
«acepto» queda por escrito. Rellena lo que va entre corchetes.

---

**Encargo de web · Mostrador**

**Cliente:** [nombre o razón social] · NIF [NIF] · [dirección]
**Prestador:** [tu nombre o razón social] · NIF [NIF] · [dirección]
**Fecha:** [fecha]

**1. Qué se entrega.** Una web de una página para [negocio], según la propuesta
que el cliente ya ha visto, en el plan **[Web Esencial · 290 € / Web Completa ·
490 €] + IVA**. Incluye el dominio [dominio.es] a nombre del cliente y el
alojamiento durante el primer año.

**2. Qué aporta el cliente.** Nombre fiscal y NIF para el aviso legal, las fotos
que quiera usar (de su propiedad) y la revisión de los textos. El cliente
garantiza que tiene derecho a usar las fotos, logotipos y textos que entrega.

**3. Plazo.** 72 horas laborables desde que el cliente entrega sus datos y
aprueba la versión final.

**4. Pago.** El cliente paga el total ([importe con IVA] €) al aprobar la
versión final y antes de publicarla, por transferencia a [IBAN] o Bizum a
[teléfono]. Se emite factura.

**5. Cambios.** Incluye [una / dos] ronda(s) de cambios antes de publicar. Los
cambios posteriores entran en el mantenimiento o se presupuestan aparte.

**6. Garantía.** Durante los 14 días siguientes a la publicación, si el cliente
no está conforme, se le devuelve el importe y se retira la web.

**7. Propiedad.** La web y el dominio son del cliente. Si deja el servicio, se le
entregan los archivos de la web y los datos de acceso al dominio.

**8. Después del primer año.** El cliente elige entre:
- **Mantenimiento:** 19 € + IVA al mes, sin permanencia. Incluye alojamiento,
  renovación del dominio, cambios de horario, precios y textos (hasta 30 minutos
  al mes), copias de seguridad y ayuda por WhatsApp.
- **Solo alojamiento y dominio:** 60 € + IVA al año.
- **Llevarse la web** a otro proveedor, sin coste.

**9. Datos personales.** Cada parte trata los datos de la otra solo para prestar
y facturar este servicio.

Para aceptar, basta con responder a este mensaje: «Acepto el encargo».

- [ ] Si se contrata mantenimiento desde el principio, indicarlo en el punto 8
